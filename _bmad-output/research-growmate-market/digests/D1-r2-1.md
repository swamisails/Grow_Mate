## Claims

24. Chronus offers six enrollment paths. Two matter here. "Application Process (Administrator Approval)": the user submits an application form, an admin approves it, and the user is notified by email. "Join directly based on eligibility criteria": the user's answers to membership questions must match criteria the admin sets, and ineligible users see a message. No criterion tied to training, an assessment or a certification is documented. | https://chronusmentor.chronus.com/en/articles/9183844-enrollment-methods-all-the-options | Chronus (help centre) | 2026-09-10 | accessed 2026-10-30 | high | feature
25. PushFar has two admin approval gates. One is at organisation level (a holding screen until an admin approves). The other is at mentor/mentee programme level, where users "won't be able to form mentoring relationships until their account is approved". Rejected users can be removed or moved to PushFar's Open Network. No eligibility criteria are documented. | https://support.pushfar.com/knowledge-base/approval-process-users | PushFar (Artgym Group) | undated (© 2026) | accessed 2026-10-30 | high | feature
26. SAP SuccessFactors Mentoring open-enrolment programmes have a "Require Mentor Approval" option. The approver is either admins/owners or the mentor's manager. With admin/owner approval, the mentor uploads supporting documents at sign-up, and the admin writes instructions on which documents to submit. Until approved, a mentor cannot be recommended or matched. Declining removes the mentor, who can sign up again (no cooldown documented). This is the closest thing found to R4, but it is a manual document review, not linked to an assessment. | https://help.sap.com/docs/successfactors-succession-and-development/using-mentoring/managing-mentoring-programs | SAP | undated | accessed 2026-10-30 | medium (from search-result extracts; the page is rendered by JavaScript and was not fetched in full) | feature

## Leads

- SAP's document-upload approval (26) is the nearest packaged way to approximate R4: the mentor uploads a certificate and an admin approves it. To check whether approval can be automated (for example triggered by an LMS completion or a verified skill in the Growth Portfolio), read the SAP help pages as PDF or the 2505 Opportunity Marketplace test script (https://help.sap.com/doc/6733411057594441afb49c7ef6ea6634/2505/en-US/Opportunity_Marketplace_in_SAP_SuccessFactors_Test_Script_6FL.pdf).
- Chronus "Join based on eligibility criteria" (24) checks profile-field answers. If a profile field could be filled by integration (HRIS or LMS sync of "Assessment L3 passed"), it would work as an indirect R4 gate. Check the Chronus help centre for profile-field sync and for the "connection settings" capacity limit.
- Other approval and capacity docs to read: Hivebrite (custom mentor application forms, https://hivebrite.io/features/mentoring/), Higher Logic ("Manage Mentoring Labels and Limits", a maximum-mentees setting, https://support.higherlogic.com/hc/en-us/articles/26046671663508-Manage-Mentoring-Labels-and-Limits) and the Qooper mentor connection-limit articles.
- ServiceNow "Create a Mentoring program" doc page (https://www.servicenow.com/docs/r/etYGEBUVr6RQYKLnfpRuhw/4Ne7yztB4wr3bWIfEQS0Cw) not yet read in full. Check it for a capacity field.
- Workday Talent Marketplace admin guide (https://doc.workday.com/admin-guide/en-us/human-capital-management/talent/talent-marketplace/req1582045401905.html) not read. Check whether mentorships appear as marketplace opportunities.
- Build accelerator: Moodle covers R3 and R5 natively (36), and conditional activities could chain L1 to L2 to L3. A Moodle badge or completion event, sent through web services, could set mentor eligibility in a custom app. Moodle badges and Open Badges 3.0 were not verified this run.
- Oasis LMS "Forced Wait between Exam Re-Attempts" and Easy LMS retake options showed up in search and may be further R5 components.

## Looked for, not found

- **The adversarial check holds.** Searches covered mentoring tools (Chronus, PushFar, SAP, ServiceNow, Workday, Together, Hivebrite in snippets). None found any product where passing an assessment or certification is a configurable, automatic precondition for mentor eligibility. Admin approval of mentor applications does exist (Chronus, PushFar, SAP with document upload), as do profile-answer eligibility rules (Chronus). R4 is therefore achievable only as a manual admin review or a custom integration.
- No retake cooldown in any mentoring product: SAP explicitly lets declined mentors sign up again immediately.
- ServiceNow Mentoring mentor capacity, accept/decline and admin assignment: not found in the release notes or search results.
- Chronus public docs on mentor capacity limits, badges and certificates: not found.
- Microsoft Viva mentoring module: not found.
- Any 2026 Absorb or Together announcement confirming or ending standalone sales: not found. The evidence is mixed (39–41).
- Not checked because the budget ran out: Absorb LMS, Docebo and TestGorilla retake delays; Badgr / Canvas Credentials Open Badges 3.0 support; SAP Opportunity Marketplace mentoring specifics; Workday mentor capacity.
